Typeface Design Agent — interactive prototype

Built by Varun Bhardwaj for the Typeface Staff PM exercise, as the companion to the 2-page PRD. Every page is walkable and the left nav is live throughout. The information architecture and visual system are modeled on the current product (mid-2026); the tenant, Meridian Athletics, is a fictional brand and all data shown is illustrative.

Flows in depth

Authority Registry→ Brief & plan→ Workspace→ Structured editing→ Approve & export

Typeface Design Agent — P0 Campaign Visual Kit. The Authority Registry keeps customer systems authoritative and compiles a versioned Brand Design Package; uploads stay supplemental until promoted. Context preflight returns Ready / Warning / Missing / Conflicted / Stale and blocks only on the last three. The agent then recommends a creation mode — reuse, adapt, or generate-new — and explains why, before you approve the Composition Plan. One direction is recomposed, not resized, into social, banner and flyer. The 12-state job machine is visible throughout.

Blocked state

The failure contract. UNSATISFIABLE_CRITICAL_CONSTRAINTS — the agent withholds an asset rather than silently dropping a required disclosure, and offers named resolutions. Reachable from Concept C.

Projects→ Arc canvas→ Visual Kit

Campaign view. An Arc with Curate / Create / Pulse tabs and one lane per agent — the Design Agent sitting beside the Email Agent as a peer.

Brand Foundations→ Connected sources→ Assets→ Audiences

Grounding. What the agent composes against — logos, palettes, text styles, fonts, trained assets, audience definitions.

What's inferred vs observed

Pages marked with a source in the card are grounded in a captured product screen. Projects and My Tasks are inferred — the nav items exist but no public footage shows those pages, so the layout is a reasonable reconstruction from sibling pages, not evidence. The Brand Design Agent pages are deliberately new — they are the proposal, built to the PRD's P0: one master key visual recomposed into social, banner and flyer. Infographics (P1) and brochures (P2) appear as explicit deferred slots with the reason, rather than being left out.
