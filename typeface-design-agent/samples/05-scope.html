Phase 1: Campaign Visual Kit · the format set

the minimum scope that proves a multi-modal agent is worth building on

The exercise names five artifact types. V1 ships three, chosen to be the smallest set that proves the thesis rather than the widest set that covers the brief. Each carries a customer reason for being in V1 and an engineering reason for being in the proving set, and those are different arguments worth keeping separate. All three compose the same five modalities from one structured document, so an edit to the master propagates instead of being redone. The goal is to learn fast: ship the least that can demonstrate real value, then use that evidence to justify the data contract and the press pipeline the advanced formats need.

Establishes

The atomic multi-modal unit. Generated text, an approved brand asset, a bounded model-generated region, a registered claim and a versioned component, composed into one artifact where every object carries its own provenance.

Establishes

That the unit is a document, not a picture. The same objects re-solved for a new ratio rather than scaled. This is the single capability both fast follows inherit most directly.

Establishes

Text as a governed object. A string that must be exact, present and legible at a minimum size, with a refusal when it cannot be. A chart label and a bound figure are the same problem.

Read the bottom row as the actual deliverable. The three formats are the vehicle; what ships is a substrate. Infographics then add one new modality, verified data bound to chart geometry, onto a document model that already exists. Brochures add pagination and a physical output path onto the same model. Neither is a second system, which is the test for whether V1 was scoped at the right level, and it is why proving these three first is what earns the investment in the rest.

Why this line

The three MVP formats were chosen to stress the runtime, not to cover the format list. Social is simple composition, banner is extreme reflow, flyer is dense hierarchy with a legal block. If those three hold up, the runtime is proven. Adding infographics or brochures first would have spent the release on a data contract or a press-production pipeline instead.
